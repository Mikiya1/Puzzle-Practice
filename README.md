# パズドラ パズル練習

パズドラのパズル練習ができるWebアプリです。

## 機能

- **盤面サイズ選択**: 6×5（標準）/ 7×6 / 5×4
- **陣プリセット**: ランダム・3色陣・4色陣・5色陣・6色陣・7色陣・回復列・火列・十字陣・市松模様
- **ドロップ操作**: マウス・タッチでドラッグ移動
- **コンボカウント**: リアルタイムでコンボ数と詳細を表示
- **手順管理**: リセット・1手戻す
- **再生機能**: 操作した手順を再生して確認
- **タイマー**: 操作開始から経過時間を計測
- **移動制限**: 手数制限の設定（練習モード）
- **ドロップ種類カスタマイズ**: 毒・猛毒・お邪魔・爆弾なども追加可能

## 技術

- HTML / CSS / JavaScript（バニラ）
- Canvas API でドロップを描画
- Vercel でホスティング
